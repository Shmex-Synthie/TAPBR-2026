## Funcoes

- **TimerLogger**: timer trigger que imprime um log a cada execucao.
- **HttpEcho**: HTTP trigger (GET) que recebe um parametro `nome` via query string e o exibe.
- **TimerCaller**: timer trigger que chama a funcao `HttpEcho` via HTTP e imprime a resposta com um texto adicional de identificacao.
